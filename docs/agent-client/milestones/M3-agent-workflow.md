# M3 本地 Agent 任务流程

状态：待启动。前置：M2 已验收。对应目标：G03、G04、G05、G06、G11。执行角色：前端、协议与工具适配、测试。

## 目标

让用户从选择项目到审阅成果完成一次真实任务：创建会话、提供上下文、确认工具操作、查看命令结果、检查文件变更、继续修正并恢复必要的修改。界面聚焦 Agent 任务，文件预览和 Diff 默认只读。

## 工作包

| 编号 | 推进动作 | 完成产物 |
| --- | --- | --- |
| M3.1 | 实现项目与会话列表、搜索、状态、继续和管理操作 | 多项目会话管理，按 Host capability 呈现支持的操作 |
| M3.2 | 实现消息、思考或状态展示、工具调用、用户问题和计划交互 | 增量渲染的聊天界面；取消和错误状态明确 |
| M3.3 | 接入文件与文本附加、工具来源和权限请求 | 用户可核对的上下文和审批界面 |
| M3.4 | 展示命令输出、退出状态、长任务与中断 | 保留真实执行状态的工具结果，不自行重复执行命令 |
| M3.5 | 实现只读预览、Diff 和 changeset 关联 | 文件增删改名、二进制说明、大文件边界与检查点入口 |
| M3.6 | 接入历史恢复、草稿和本地显示偏好 | Host 与 UI 存储职责分离；断线与崩溃场景回放 |
| M3.7 | 用固定项目执行完整任务并独立检查成果 | T03 至 T07、T12 的阶段证据 |

## 交互合同

Host 是消息、工具、会话和变更状态的权威。UI 的乐观状态必须在确认或失败后收敛；前端草稿不能覆盖已经发送的用户消息。审批显示真实命令、路径或工具参数的必要信息，并遵守对应运行时的权限语义。

会话与聊天使用协议提供的精确身份，多项目中的同名文件和会话不得混用。工具调用只有实际执行方能够宣布成功，UI 不能把请求发出当成执行完成。

Diff 优先使用轻量只读组件，计算复用 Host 或底层算法。检查点和恢复沿用 Host 实际支持的操作；用户在 Agent 修改后自行编辑过文件时，先显示冲突或限定恢复范围，不无提示覆盖。

若完整终端模拟器不是当前工具所需，先展示命令输出；当实际会话需要交互式终端时，按 capability 接入终端通道和按需终端视图。代码块本身不拥有执行权限。

## 交付物

首个可用于日常项目任务的 Alpha、完整任务录屏或截图、可复现 fixture、权限和恢复行为说明。证据计划存入 `evidence/M3/`，其中记录真实任务的文件 diff 与确定性检查结果。

## 验收门禁

- [ ] T03 在两个项目、三个会话间交错执行，历史、工具、上下文与模型选择不会串用。
- [ ] T05 至少修改两个文件并执行检查，独立验证成果和命令退出状态，而不是只阅读 Agent 自述。
- [ ] 用户问题、计划确认、工具拒绝、工具失败和取消均有可恢复界面；拒绝后无副作用。
- [ ] T06 覆盖 CRLF、Unicode、空文件、增删改名、二进制、大文本与外部修改；恢复不覆盖后续用户内容。
- [ ] 断线和崩溃后可继续已持久化会话，未知结果请求不会被自动重发。
- [ ] UI 没有常规代码编辑、调试和补全入口；输入和 Diff 不加载完整 workbench。

## 风险与处理

不能获得语言诊断时，界面明确区分“没有诊断提供者”和“没有错误”。按 M0 清单用项目检查命令或后续语言服务补齐，不能返回空列表伪装成功。完整任务失败时按 UI、协议、Host、运行时和工具分别归因。
