# Agent 客户端验证与证据规范

功能正确、兼容范围和资源收益分别验证。功能门禁优先使用确定性 fixture 与已有回放基础设施；真实 Copilot 场景验证登录、运行时和完整任务。测试不会直接使用用户正在工作的仓库，文件修改、恢复与进程故障均在临时测试项目中完成。

当前产品范围按 [ADR-001](ADR-001-agent-first-dsh-extension.md) 的 Agent First 与 DSH VSIX 适配执行，增加 AF-01–06 门禁；旧原型测试保留原提交和平台边界，不作为新架构通过的证据。真实 DSH 任务和原插件对照单独记录。

## 验收证据

每次里程碑验收在未来的 `evidence/` 目录记录以下信息；该目录当前不代表已有测试结果。

| 字段 | 需要记录的内容 |
| --- | --- |
| 身份 | 里程碑、目标和场景编号、被测提交、依赖锁文件与构建清单 |
| 环境 | Mac 型号、CPU 架构、内存、macOS、Node、实际容器、VSC SHA/proposals、DSH VSIX/驱动/runtime/profile/插件锁、AHP/Copilot 版本 |
| 配置 | 项目与历史数据集、账户类型而非账户凭据、模型、插件与扩展版本、权限模式 |
| 操作 | 可复现命令或手工步骤、输入、期望结果、实际结果和持续时间 |
| 证据 | 脱敏日志、进程列表、测试报告、截图或录屏、原始性能采样 |
| 判定 | 通过或失败、阻塞问题、责任角色、复验条件与已知限制 |

账户令牌、连接令牌、私有代码和聊天原文不进入公共证据；需要真实内容的 fixture 使用专门测试项目。记录配置变化，不能把不同能力组合的结果直接合并。

## 功能场景目录

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| T01 | 独立 Host、登录和鉴权 | 使用应用管理的依赖启动；正确令牌能连接，错误令牌不能执行；真实 Copilot 登录、过期、登出和再次登录可观察；无凭据写入参数、日志或诊断包 |
| T02 | 原 Agent 界面与平台 | 原 ChatWidget/Input/列表调用链通过；按实际容器真机验证中文输入法、粘贴、文件选择、拖放、长代码块、外链和键盘导航；无常规编辑器与调试入口；富内容不能调用原生 shell |
| T03 | 多项目会话 | 两个临时项目、三个会话交错发送与取消；创建、恢复、重命名、归档、删除和模型切换按 capability 运作；另一个客户端看到同一已确认状态 |
| T04 | 断线与并发 | 流式响应、用户问题、工具待审批和工具执行中分别断线；恢复后与 Host 快照收敛；不重复创建会话或执行命令；未知结果可查询或明确显示 |
| T05 | 真实代码任务 | 固定项目要求搜索、读取、修改至少两个文件并执行确定性检查；独立验证 diff 和检查输出；工具失败、中断、非零退出状态也正确展示 |
| T06 | 上下文和变更 | 测试手动附加文件、空文件、CRLF、Unicode、增删改名、二进制、大文件和用户外部修改；只读预览正确；恢复不会无提示覆盖后续用户修改 |
| T07 | 权限与内容边界 | 对文件、命令、MCP、扩展工具分别批准和拒绝；拒绝后无副作用；路径越界和失效审批按 Host 规则拒绝；HTML、Markdown 与恶意插件内容无法越过原生桥权限 |
| T08 | 原生插件生命周期 | 用受控 stdio MCP、测试 HTTP MCP、Skill、自定义 Agent、指令、Prompt、Hook 和复合插件逐项验证发现、调用、作用域、禁用、卸载、进程失败和重启恢复；无实际支持的格式报告不支持 |
| T09 | 原 Agent 扩展与准入 | 在原宿主/API 下验证文件/配置工具、MCP、声明式资源和所有准入必选扩展；编辑器专用和未准入混合扩展在 startup/命令/语言/运行依赖路径均未激活；DSH VSIX 接入原列表/聊天；依赖、卸载和宿主故障可诊断 |
| T10 | 浏览器与富交互 | 浏览器工具对本地测试站点导航、截图、交互并取消；Canvas 在运行时确实支持时列举、打开、调用和恢复；无能力时展示准确状态，不能以静态截图宣称交互兼容 |
| T11 | 产物和启动裁剪 | 检查打包清单、模块图、动态路径、worker/服务和实际插件激活；editor-only 负向清单未主动加载、编辑器专用扩展入口未执行；必要 Monaco/工作台依赖有用途/尺寸，DSH runtime/插件/首次下载均计入；容器不以“无 Electron”代替裁剪验收 |
| T12 | 进程与数据恢复 | 关闭窗口、退出、重启、Host 崩溃、运行时崩溃、应用异常退出分别测试；已持久化历史可恢复；自有进程清理，外部进程不误杀；干净 Mac 安装后完成 T05 |
| T13 | 分发与双上游维护 | 签名、公证和隔离属性下首次运行通过；VSC/DSH 分别真实更换提交并回归，适配器/驱动独立配对；更新失败恢复与整组版本/数据回退通过，不只改版本号或锁文件代替升级演练 |

确定性工具场景由 fixture 控制事件、时序和副作用；真实模型场景重复至少 3 次，记录全部成功与失败。模型输出不同于协议或工具故障时分开归因，不自动删除失败样本。必选场景有未解释故障就不能标为通过。

## 基线和数据集

- B0：当前源码构建的常规 VS Code 配置，用于说明用户可感知的总体差异。
- B1：同一源码构建的 Sessions，关闭无关扩展，但启用与候选产品相同的必选 Agent 能力。这是性能验收的主基线。
- C0：候选 Agent First 应用，保留首版 VSC 核心和原 Agent 能力，DSH 未激活；记录原宿主是否因其他必选插件启动，不强行关闭原宿主作为性能捷径。
- C1：相同候选应用，启用必选 Agent 扩展、DSH 及所需前端/富交互；记录实际全部进程。Electron/Tauri 分别测，容器之间保持相同原组件与功能。

B1 按 C0、C1 分别建立匹配配置，DSH 另有同版本/profile/插件锁的原生运行对照。共同必选能力、模型、工具与数据集一致；受控工具耗时使用同一个执行服务。C0 成绩不能代替 C1 验收。B0 不适用的功能标明差异，不强行给出同能力结论。新版基线与预算校准在优化前记录，旧百分比不自动通过。

固定数据集包括两个代码项目、100 个会话目录、当前会话 1000 条显示事件、一个大文本 Diff、MCP fixture 和扩展样本。项目体积、文件数、消息大小、流式事件速率、Diff 行数及生成种子在 M0 固定并版本化，后续成绩引用同一数据集版本。

## 性能测量流程

| 编号 | 测量方式 | 统计与报告 |
| --- | --- | --- |
| P01 | 在干净用户目录安装，完成必要依赖获取后测量磁盘占用；分列安装包、解压体积、必需运行时、首启下载与工作数据 | 一次完整清单加两次独立安装复核；必需组件全部计入，测试历史与缓存另列 |
| P02 | 启动并打开相同数据，稳定 60 秒后每秒采样一次，持续 120 秒；归属主进程、WebView、Host、运行时、worker 和扩展宿主 | 聚合 footprint 作为固定口径代理指标并保留逐进程原值；RSS 单列；报告内存中位值、p95、CPU 中位值和后台活动 |
| P03 | 冷启动用无应用进程的受控系统冷缓存或重启环境重复至少 20 次；暖启动在资源已缓存且应用完全退出后重复至少 30 次 | 分开记录进程启动、首屏、可交互、Host ready、会话可用；报告中位值与 p95；不把清用户配置当作清系统缓存 |
| P04 | 固定历史下重复 100 次中文输入与已缓存会话切换，使用界面时间戳和真实呈现帧测量；流式输出场景另测 | 报告 p95、主线程长任务和帧延迟；不能只测事件处理函数耗时 |
| P05 | 重复打开关闭同一长会话 20 次，每轮执行相同步骤并等待稳定；同时执行持续 30 分钟的受控流式工具任务 | 报告首次与末次稳定内存、增长趋势、队列长度和进程存活；自然回收后采样，不靠仅某个版本强制 GC 达标 |
| P06 | 相同受控本地工具任务重复至少 30 次，分别测请求、Host 调度、执行、结果投影和 UI 呈现 | 报告本地调度 p95；工具本身耗时与网络、模型耗时单列；记录事件数量和序列完整性 |

同一硬件、电源模式、系统版本、项目磁盘和构建优化级别下交替运行 B1 与候选版本。远程模型首 token 和总任务耗时另列，不能作为客户端语言更快的证据。记录所有样本及异常原因；存在测量噪声时增加样本并复验，不选择性丢弃慢样本。

## 发布判定

G01 至 G12 对应场景全部通过，性能符合 `GOALS.md` 预算，兼容清单内的必选扩展全部通过，才进入发布候选。发布不能通过删除必选能力或隐去未计入的进程来满足数字。没有签名、公证或干净机器证据时只能标记为开发预览。

每项失败都要归因到客户端、AHP、Host、运行时、扩展或外部服务。修复后复验受影响场景；已经成功且输入未改变的结果可继续使用，不为凑验收重复运行无关的大型测试。
