# Agent 客户端目标与验收标准

首版必须提供可独立运行的 Copilot Agent 应用，同时保留约定的 Agent 扩展能力。下面是目标和验收条件的唯一总表；具体操作和测量口径见[验证与证据规范](VALIDATION.md)。全部目标当前为待验收。

## 功能和工程目标

| 目标 | 目标描述 | 验收标准 | 里程碑 | 验证场景 |
| --- | --- | --- | --- | --- |
| G01 | 独立运行与可分发 | 在无 VS Code、无系统 Node、无开发工具的干净 macOS arm64 环境安装并启动；仅凭应用包含或明确管理的依赖完成真实 Copilot 任务；构建与原生模块使用匹配的 Node ABI | M1、M7 | T01、T12 |
| G02 | Agent 专用界面 | 沿用同源码 VS Code Agent/Sessions 的布局、主题和核心交互，组件来源与平台适配见 [界面迁移](UI_MIGRATION.md)；默认提供项目、会话、聊天、工具、变更和设置；通过同主题同任务的界面对照；不提供常规代码编辑工作台、语言补全或调试器入口；前端产物不包含 `editor.all` 和通用 workbench 入口 | M2、M3、M6 | T02、T11、UI01 至 UI06 |
| G03 | 会话与任务管理 | 创建、继续、重命名、归档和删除遵循 Host 能力；支持流式输出、取消、用户问题和计划交互；两个项目、至少三个会话交错运行时历史与状态不串用；同一会话连接两个客户端后状态收敛 | M2、M3 | T03、T04 |
| G04 | 文件和命令任务流程 | Agent 能搜索、读写多文件并运行命令；界面正确展示工具状态、结果、错误、退出状态和取消；固定项目任务产生可验证的预期修改及测试结果 | M1、M3 | T05 |
| G05 | 变更审阅与上下文 | 可附加明确选定的文件或文本；可查看只读文件、文本 Diff、增删改名和二进制变更说明；支持 Host 已提供的检查点或变更恢复；存在外部修改时不会无提示覆盖 | M3 | T06 |
| G06 | 登录和执行权限 | 连接鉴权与 Copilot 账户鉴权分别有效；凭据不会出现在 UI 日志、命令行参数或导出的诊断包；工具审批由 Host 或对应运行时执行，拒绝后不执行；客户端富内容不能直接获得宿主命令权限 | M1 至 M5、M7 | T01、T07 |
| G07 | 原生 Agent 扩展能力 | MCP、Skills、Agents、Instructions、Prompts、Hooks 和插件具备明确的作用域与启用状态；协议或运行时支持的安装、调用、禁用、卸载和恢复路径通过；不存在通用支持的格式不得宣称兼容 | M4 | T08 |
| G08 | 适用的工具扩展与富交互 | 兼容清单中的所有首版必选扩展通过；至少一个文件或配置工具扩展、一个 MCP 提供扩展和一个声明式 Agent 资源扩展可用；扩展宿主按需启动；浏览器和 Canvas 按 M0 的首版清单验收 | M5 | T09、T10 |
| G09 | 可衡量的性能改善 | 完整首版能力下达到本页性能预算；分别报告关闭兼容宿主和启用必选扩展两种模式，不用模型或网络耗时掩盖本地性能 | M0、M6 | P01 至 P06 |
| G10 | 产物真正裁剪 | 发布包不含 Electron、通用工作台前端和未列入清单的编辑器扩展；保留的 VS Code 基础组件逐项可解释；worker、动态资源、原生模块和运行时依赖计入清单及尺寸 | M1、M5、M6 | T11 |
| G11 | 故障恢复与数据可靠性 | 网络中断不丢失 Host 已确认的消息；副作用请求在结果未知时不自动重发；进程崩溃可诊断并恢复已持久化会话；关闭窗口与退出应用行为明确，退出后无自有孤儿进程 | M2、M3、M7 | T04、T12 |
| G12 | 发布和持续维护 | 支持签名、公证、首次安装、更新失败恢复与兼容回退；上游版本、AHP、Copilot SDK 和运行时形成可追踪版本组合；第三方依赖说明随包；发布场景全部通过 | M7 | T12、T13 |

## 性能预算

以下是规划默认验收目标，M0 完成后可以根据实际硬件和基线做一次有记录的校准。后续不得为了让结果通过而追溯修改目标；范围或指标调整必须在实现前写明原因和受影响的产品承诺。

主比较基线 B1 是同一源码版本、仅启用约定 Agent 能力的现有 Sessions 桌面应用；B0 是常规应用配置，只用于解释总体收益。两者使用相同项目、历史、账户配置与工具扩展集合。具体流程以 `VALIDATION.md` 为准。

| 指标 | 首版验收目标 | 对应验证 |
| --- | --- | --- |
| 完整安装占用 | 相对 B1 减少至少 40%；包含随包和首次运行必须获得的 Node、Copilot 运行时、原生依赖、必选扩展与静态资源 | P01 |
| 空闲进程组资源 | 相对 B1 的聚合内存代理指标减少至少 30%；后台 CPU 中位值不高于 B1，固定空闲场景不持续轮询项目 | P02 |
| 冷启动交互时间 | p95 相对 B1 改善至少 25%；分别报告界面可交互和会话可用时间，模型首 token 不纳入本地启动指标 | P03 |
| 暖启动和基本交互 | 暖启动可交互 p95 不超过 1.5 秒；输入响应 p95 不超过 100 毫秒；已缓存会话切换 p95 不超过 200 毫秒 | P03、P04 |
| 大历史和长任务 | 在 100 个会话目录、当前会话 1000 条显示事件下仍满足交互预算；20 次打开关闭循环并稳定后，内存代理指标相对首次稳定值增长不超过 10% | P04、P05 |
| 协议与工具开销 | 相同本地确定性工具任务的端到端调度耗时 p95 不高于 B1 的 110%；没有协议队列无限增长或流式事件丢失 | P06 |

“聚合内存代理指标”使用一致的 macOS 采样方式统计应用、归属 WebView 进程、Node Host、运行时、worker 和必选扩展宿主；逐进程 footprint 与 RSS 分开报告，不把简单 RSS 求和称为唯一物理内存。CLI 工具进程在任务场景计入，在空闲场景确认已经退出。

## 扩展兼容等级

| 等级 | 产品承诺 | 验收要求 |
| --- | --- | --- |
| A 原生 Agent 资源 | 受支持格式的 MCP、Skills、Agents、指令、Prompts、Hooks 和插件 | 明确格式、来源、版本、作用域和生命周期；T08 通过 |
| B 兼容工具扩展 | 经审计的 VS Code Agent 工具扩展 | 固定扩展版本，记录真实 API 依赖；T09 通过后才进入兼容清单 |
| C 混合或富交互扩展 | 同时依赖工具、编辑器或自定义视图的扩展 | 拆分、迁移或提供独立桥接后逐项验证；T10 通过的能力才可用 |
| D 编辑器扩展 | 仅服务补全、编辑、调试和传统工作台的扩展 | 不安装、不激活，不作为首版兼容承诺 |

M0 将具体扩展和浏览器、Canvas 等能力标为“首版必选、首版可选、后续、移除”。必选项无法完成就阻塞发布，不能悄悄改名为可选；可选项必须明确展示可用性，不能静默执行空操作。

## 范围约定

首版以 Copilot Agent Host 为运行基线。旧 Local harness 的编辑器上下文、自动语言诊断、调试器上下文、未保存编辑缓冲区，以及云端会话、远程开发、自动化调度等行为分别建表，不因保留 Copilot 名称就视为自动覆盖。语言诊断可在确有需求时以项目检查命令或独立语言服务补齐，其效果需单独验收。

保留少量 `editor/common` 文本和 Diff 算法是允许的；默认前端不加载 Monaco。若只读 Diff 或输入体验确实需要 Monaco，应以延迟加载和独立性能对照决定采用，不因此恢复通用代码编辑工作台。
