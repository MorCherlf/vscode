# Agent 客户端目标与验收标准

首版提供可独立运行的 VSC Agent First 应用，保留约定的 Copilot/Agent 能力，以原 VS Code 插件机制承载 DSH 适配器。2026-10-29 按 [ADR-001](ADR-001-agent-first-dsh-extension.md) 收窄范围：编辑器专用插件禁用，editor-only 组件不主动加载，必要的原 Agent 编辑器依赖保留；DSH 插件由原运行时加载。下面是目标和验收条件的唯一总表；原场景口径见[验证与证据规范](VALIDATION.md)，新增门禁见 ADR 的 AF-01–06。全部目标仍为待验收，方向调整不改变已有证据的真实边界。

## 功能和工程目标

## 性能预算

以下是规划默认验收目标，M0 完成后可以根据实际硬件和基线做一次有记录的校准。后续不得为了让结果通过而追溯修改目标；范围或指标调整必须在实现前写明原因和受影响的产品承诺。

下表源于早期 Tauri/独立 Host 范围，当前没有完整实测结果。ADR-001 增加原组件、原宿主和 DSH 的同能力范围后，先建立新版 B1 和全进程/依赖基线，再于优化实施前记录预算校准；下表作为旧预算保留，不能按新方案自动标通过，也不能用缺失 DSH/原插件功能的成绩替代。

主比较基线 B1 是同一源码版本、仅启用约定 Agent 能力的现有 Sessions 桌面应用；B0 是常规应用配置，只用于解释总体收益。两者使用相同项目、历史、账户配置与工具扩展集合。具体流程以 `VALIDATION.md` 为准。

| 指标 | 首版验收目标 | 对应验证 |
| --- | --- | --- |
| 完整安装占用 | 相对 B1 减少至少 40%；包含随包和首次运行必须获得的 Node、Copilot 运行时、原生依赖、必选扩展与静态资源 | P01 |
| 空闲进程组资源 | 相对 B1 的聚合内存代理指标减少至少 30%；后台 CPU 中位值不高于 B1，固定空闲场景不持续轮询项目 | P02 |
| 冷启动交互时间 | p95 相对 B1 改善至少 25%；分别报告界面可交互和会话可用时间，模型首 token 不纳入本地启动指标 | P03 |
| 暖启动和基本交互 | 暖启动可交互 p95 不超过 1.5 秒；输入响应 p95 不超过 100 毫秒；已缓存会话切换 p95 不超过 200 毫秒 | P03、P04 |
| 大历史和长任务 | 在 100 个会话目录、当前会话 1000 条显示事件下仍满足交互预算；20 次打开关闭循环并稳定后，内存代理指标相对首次稳定值增长不超过 10% | P04、P05 |
| 协议与工具开销 | 相同本地确定性工具任务的端到端调度耗时 p95 不高于 B1 的 110%；没有协议队列无限增长或流式事件丢失 | P06 |

“聚合内存代理指标”使用一致的 macOS 采样方式统计应用、归属 WebView 进程、Node Host、运行时、worker 和必选扩展宿主；逐进程 footprint 与 RSS 分开报告，不把简单 RSS 求和称为唯一物理内存。CLI 工具进程在任务场景计入，在空闲场景确认已经退出。

## 扩展兼容等级

| 等级 | 产品承诺 | 验收要求 |
| --- | --- | --- |
| A 原生 Agent 资源 | 受支持格式的 MCP、Skills、Agents、指令、Prompts、Hooks 和插件 | 明确格式、来源、版本、作用域和生命周期；T08 通过 |
| B 原 VSC Agent 扩展 | 经审计、只需保留 Agent 能力的扩展，包含 DSH Adapter VSIX | 固定扩展版本，在原宿主/API 下验证 T09/AF-03，提案 API 按配套产品 allowlist |
| C 混合或富交互扩展 | 同时含 Agent 与编辑器/视图依赖的扩展 | 默认不自动启用，审计整个激活/导入/依赖路径；无法保持 Agent First 时禁用或由作者拆包，不恢复常规 IDE |
| D 编辑器扩展 | 仅服务补全、编辑、调试和传统工作台的扩展 | 自有分发不安装，已有安装也禁止激活；依赖/命令/语言/startup 不得绕过 |
| E DSH 原生插件 | 固定 DSH/profile/包锁下的原 Cordis/backend/client 插件 | 后端行为按 AF-04 对照，前端按 AF-05 单独验收；不逐插件重写或默认改造成 tool |

M0 将具体扩展和浏览器、Canvas 等能力标为“首版必选、首版可选、后续、移除”。必选项无法完成就阻塞发布，不能悄悄改名为可选；可选项必须明确展示可用性，不能静默执行空操作。

## 范围约定

首版保留 Copilot Agent Host 已有成果，并新增 DSH Adapter VSIX + 原运行时接入。旧 Local harness 的编辑器上下文、自动语言诊断、调试器上下文、未保存编辑缓冲区，以及云端会话、远程开发、自动化调度等行为分别建表，不因保留名称就视为自动覆盖。语言诊断可在确有需求时以项目检查命令或独立语言服务补齐，其效果需单独验收。

原输入、代码块和只读 Diff 需要的 Monaco/文本/服务允许按需使用，不为“无 Monaco”重写原组件。editor-only 的排除依据真实用途与加载清单，不能仅按目录名判断；不因此恢复常规编辑工作台。旧方案与本次定义的差异已在 ADR-001 记录，所有新门禁仍待执行。
